# SentinelAI

## AI-Powered Cybersecurity Incident Response Platform

SentinelAI is an intelligent cybersecurity platform that helps security analysts detect, investigate, and respond to cyber threats using Artificial Intelligence.

## Features

- AI-powered threat detection
- Security log analysis
- Incident management
- Risk assessment
- AI security assistant
- Interactive dashboard
- Automated incident reports

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Framer Motion

### Backend
- FastAPI
- Python

### AI
- OpenAI API
- LangChain
- LangGraph

### Database
